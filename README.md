# Фронт і тил

Самостійна браузерна покрокова стратегія, натхненна простою картою та перекиданням сил у [«Битві за Україну» MaxD](https://demo.devs.mx/ukraine/). Усі код, схематична географія, графіка інтерфейсу та правила цієї реалізації створені заново.

**Грати онлайн:** https://serge-sotnyk.github.io/battle4ua-codex/

## Запуск

Потрібен **Node.js 18 або новіший**. Встановлювати пакети не потрібно.

```sh
git clone https://github.com/serge-sotnyk/battle4ua-codex.git && cd battle4ua-codex
npm start
```

Відкрийте **http://localhost:5173**. Зупинка сервера — `Ctrl+C`.

Якщо порт зайнятий:

```sh
PORT=5174 npm start
```

Сервер слухає лише `127.0.0.1`. Гра не звертається до зовнішніх сервісів, не завантажує шрифти чи графіку з мережі та не має платних залежностей. Альтернативний запуск — `python3 -m http.server 5173 --bind 127.0.0.1` з кореня репозиторію. Після першого відкриття під час роботи сервера всі розрахунки відбуваються у браузері.

## Як грати

1. Виберіть сторону, кампанію та складність.
2. Натисніть власний сектор на карті. Заплануйте наступ, перекидання, поповнення, відновлення або укріплення.
3. Використайте розділи **Технології**, **Операції** та **Море** для розвитку й впливу на тил.
4. На тиждень доступні **чотири накази**; одне угруповання виконує один наказ. До завершення ходу все можна скасувати з поверненням витрат.
5. Натисніть **Завершити хід**. Противник незалежно планує свої дії; бої розраховуються одночасно. Читайте оперативний журнал.

Карта підтримує перетягування, масштабування колесом та кнопками, вибір секторів з клавіатури. Шар **Постачання** показує стан власних секторів і маршрути сусідства. Географія схематична: для правил бою використовується заданий граф сусідства, а не видима довжина кордону.

### Перші стратегічні рішення

- Велика армія в тилу не допомагає фронту без перекидання. Маршрут займає один сектор за хід; дослідження логістики прискорює його.
- Підкріплення з резерву прибуває наступного ходу. Бюджет списується під час планування.
- Північна загроза видима: Брянськ → Чернігів, Курськ → Суми. Білорусь у двох початкових сценаріях нейтральна.
- Готовність і постачання важливіші за саме число сили. Наступ виснажує; відновлення повертає готовність і прискорює ремонт.
- Скоординуйте наступ із кількох секторів: після захоплення 45% сил **кожного** угруповання, що вижило в цьому наступі, займають новий сектор. Готовність переходить разом із ними.
- Захоплену територію потрібно утримати. Заздалегідь готуйте резерви та маршрут; слабке нове угруповання вразливе для контратаки.
- Розвідка відкриває точні дані на три ходи. Прогноз наступу спирається на доступну оцінку й не враховує ще не виконаних наказів противника.

### Кампанії

| Кампанія | Українська ціль | Тривалість |
| --- | --- | --- |
| Повернення | Контролювати всі 25 українських секторів два послідовні ходи | До 36 тижнів |
| Тримати рубіж | Зберегти Київ і щонайменше 19 секторів на завершенні кампанії | 20 тижнів |

Російська ціль — захопити Київ або не дати Україні виконати її ціль до кінця кампанії. Повернення та утримання всіх секторів також достроково завершує оборонну кампанію перемогою України.

Це умовні альтернативні сценарії. Стартові сили, кордони контролю, ефекти технологій і календар не відтворюють поточну військову ситуацію. У першій альфа-версії баланс ще потребує живих партій; «Повернення» вимагає підготовленого наступу, а «Тримати рубіж» — оборонного плану.

### Збереження

Автозбереження працює після наказів, їх скасування, вибору підтримки й завершення ходу. На стартовому екрані з’явиться **Продовжити збереження**. Воно прив’язане до браузера й адреси: інший порт або браузер має окреме сховище.

У меню **Збереження** можна експортувати JSON і відновити його в іншому браузері. Імпорт перевіряє версію, стан, ресурси та законність запланованих наказів. Перед імпортом або початком нової кампанії експортуйте поточну партію, якщо хочете зберегти її окремо.

Клавіші: `Enter` — завершити хід; `Esc` — скасувати вибір цілі / закрити діалог; `+` / `-` — масштаб; `0` — вся карта; `?` — правила. Стрілки переміщують карту, коли вона у фокусі.

## Архітектура

| Файл | Відповідальність |
| --- | --- |
| `src/data.js` | Сектори, граф сусідства, географія SVG, сценарії, технології |
| `src/engine.js` | Стан кампанії, законність наказів, бої, постачання, рух, ШІ, збереження |
| `src/app.js` | Інтерфейс, SVG-карта, керування, діалоги, локальне сховище |
| `styles.css` | Візуальна система та адаптивне компонування |
| `server.mjs` | Локальний статичний HTTP-сервер на стандартних модулях Node.js |
| `tests/engine.test.js` | Правила, регресії, перевірка повних кампаній |
| `scripts/balance.mjs` | Приблизна симуляція тестового гравця для дослідження балансу |

Рушій не залежить від DOM. `endTurn(state)` повертає новий стан, не змінюючи вхідний. Випадковість має збережений seed: однакові стан та накази дають однакові результати. ШІ користується тим самим бюджетом, резервом, лімітом наказів і доступними оцінками противника. Звичайний ШІ обережніший і задовольняється одним рівнем укріплень; досвідчений частіше атакує та створює глибшу оборону.

Докладні рішення й порядок розрахунків — у [docs/DESIGN.md](docs/DESIGN.md).

## Перевірки

```sh
npm run check
npm test
node scripts/balance.mjs 100
```

Тести перевіряють витрати й повернення ресурсів, обмеження наказів, час руху й досліджень, переривання маршрутів, туман війни, одночасні бої, скоординовані наступи, перемоги та збереження. Сотня повних кампаній перевіряє також збереження загальної кількості сили: наявні війська + втрати = стартові війська + отримані підкріплення. Показники симулятора залежать від його спрощеної стратегії й не є оцінкою ймовірності перемоги людини.

## Наступні можливі кроки

Живі партії й налаштування балансу; додаткові карти та сценарії; окремі моделі тактичної підтримки й різних типів далекобійних ударів; активна Білорусь у новому сценарії; передача ходів між двома гравцями. Поточна гра повністю працює як локальна одиночна кампанія.

Для майбутнього розміщення достатньо статичного хостингу файлів `index.html`, `styles.css` і `src/`. Node-сервер потрібен для зручного локального запуску.
